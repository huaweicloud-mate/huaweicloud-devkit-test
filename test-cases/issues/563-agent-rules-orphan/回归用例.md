# #563 全局规则 huawei-agent-rules.mdc 无代码注入（回归用例）

- **关联设计用例**：`D4-23`（全局规则 huawei-agent-rules.md 注入生效性，P0）
- **严重级**：P1

- **上游**：https://github.com/huaweicloud/huaweicloud-devkit/issues/563

## 根因

`rules/huawei-agent-rules.mdc`（后改名 `.md`）为**孤儿文件**——注释承诺"注入到 agent 系统提示/规则"，但实际**无代码读取/注入**，MUST 约束（禁直连 csms/kms）未进任何 agent 上下文。

## 复现步骤

1. 安装后逐目标核对 rules 是否注入系统提示/规则（11 个安装目标）。
2. 构造「禁直连 csms/kms」场景，观察 Agent 是否遵守 MUST 约束。
3. 检查 rules 文件是否仍为孤儿（无读取代码、无注入点）。

## 断言契约（回归判定标准）

| # | 断言 | 期望 |
|---|---|---|
| 1 | rules 注入 | 全部目标注入系统提示/规则，非孤儿文件 |
| 2 | MUST 约束 | 禁直连 csms/kms 场景下约束被遵守 |
| 3 | 无孤儿 | 仓库内无「有文件但无代码引用」的规则文件 |

**唯一断言口径**：以「存在注入代码路径 + 约束实际生效」判定，不采用"文件存在即认为生效"替代。

## 证据

- ITER-002 实测（D4-23 孤儿延续）；修复后按 D4-23 逐目标注入复验。

## 回归结论

修复后核对 11 目标注入 + MUST 约束生效，全过才关闭。
