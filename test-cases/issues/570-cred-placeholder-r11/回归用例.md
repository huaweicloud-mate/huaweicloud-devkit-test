# #570 码道占位符遮蔽真实凭证 R11 归零（回归用例）

- **关联设计用例**：D2 认证维度（凭证来源/优先级负向）；占位符/脱敏值遮蔽为**新增负向场景**，建议母版新增 D2 负向用例锚定「R11 归零」（待设计阶段与 `design/` 母版对齐具体编号）
- **严重级**：P0（真实凭证被占位符遮蔽 → 云操作全失败 + 诊断误导，凭证正确性 + 功能中断）
- **状态**：**已修复**（1.1.4-next.4，commit `93e5743`；2026-09-14 12:03 函数级实测 28/28 PASS）
- **上游**：https://github.com/huaweicloud/huaweicloud-devkit/issues/570

## 根因

`credentials.mjs` 的 `resolveCredentials()` + `readCodeArtsCredentials()` 只用 **truthy 判断凭证**（`if (ak && sk)`），不识别占位符/脱敏值。码道 IDE 市场安装把 `<HW_ACCESS_KEY>` / `<HW_SECRET_KEY>` 占位符写进 mcp_settings env，被当成有效凭证，遮蔽 S1 中用户真实凭据 → 「连接成功但云操作全失败」，指纹诊断误导。

## 修复实现（commit 93e5743，已含入 1.1.4-next.4）

- 新增 `isPlaceholder()`（`credentials.mjs:66-82`）：尖括号 `<>` / 模板插值 `${}` / 裸关键词 `AK|SK|ACCESS_KEY|SECRET_KEY|TOKEN|REGION`（含 `YOUR_` 前缀）/ `placeholder|replace_me|change.me` / 脱敏值 `前缀3-8位+星号` / 纯星号 → 判定占位。
- 新增 `present()`（`:84-86`）= 非空字符串且 `!isPlaceholder`。
- 四处入口归一：env（`:130-132`）/ S1（`:146-148`、R9 标记门 `:155`）/ CodeArts S4（`:222`、`:245`）/ scanState（`reconcile.mjs:108-114` + `envIsPlaceholder:162`）。
- STS 三件套门用 `present()` 重算（`credentials.mjs:165-166`）→ **占位符三件套永远不算平台注入**。
- 额外容错：S4 server key 宽容匹配 `'HuaweiCloud DevKit'`（`:217`、`:241`）。
