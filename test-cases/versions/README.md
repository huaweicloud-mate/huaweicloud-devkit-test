# versions 版本测试设计目录

本目录按**被测版本**建子目录，存放各版本的测试设计与用例快照（冻结归档，与母版真源分离）。

## 与母版的关系

| 目录 | 性质 | 内容 |
|---|---|---|
| `test-cases/design/` + `expanded/` | **母版真源**（跨版本演进） | 当前最新用例 163 设计级 + 137 展开级 |
| `test-cases/versions/<版本>/` | **版本冻结快照**（归档） | 该版本的测试设计文档 + 用例矩阵快照 |

母版真源遵循「ID 一经分配永不复用 / OBSOLETE 标记 / 修改=新 ID」三铁律；版本子目录是**某一时间点的冻结切片**，用于版本间对比与审计回溯，不随母版演进。

## 每个版本子目录的固定结构

```
versions/<版本>/
├── 迭代测试设计.md               # 测试对象 / 目标 / 范围 / 策略 / 环境 / 缺陷管理
├── 用例矩阵-设计级-<版本>.csv     # 设计级用例快照（冻结）
└── 用例矩阵-展开级-<版本>.csv     # 展开级用例快照（冻结）
```

新版本发布时，从 `design/` + `expanded/` 复制当前 CSV 到 `versions/<新版本>/` 并补一份迭代测试设计文档。
