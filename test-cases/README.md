# 用例体系说明

本目录存放 huaweicloud-devkit 测试用例**母版**（跨版本演进，非执行结果）。

## 文件

| 路径 | 内容 |
|---|---|
| `design/用例矩阵-设计级.csv` | 设计级用例 163 条（D1–D10；完整设计字段 + 独立设计/执行状态 + 多终端元数据；2026-09-11 全量评审补充 9 条：D1-56/57、D2-21、D3-C7~9、D4-24、D6-8、D9-9） |
| `design/gen_matrix.py` | 矩阵生成脚本（修改后重跑保证可复现） |
| `expanded/用例矩阵-展开级.csv` | 展开级用例 137 条（D5 客户端矩阵 70 / D3-C4 服务矩阵 22 / D10 评测集 15 / NR3 终端展开 25 / D1-58 白名单 5） |
| `daily/用例矩阵-设计级.csv` + `daily/用例矩阵-展开级.csv` | 每日基础用例（81 设计级 + 71 展开级，母版设计字段列，不带执行状态/结果） |
| `gen_daily.py` | 每日基础用例生成脚本（规则改后重跑） |
| `versions/<版本>/` | 各版本测试设计文档 + 用例矩阵快照（冻结归档） |
| `issues/<编号>-<slug>/` | 缺陷级定向回归用例（复现 + 断言 + 结论） |

## 目录分区（三区 + 母版真源）

```
test-cases/
├── design/ + expanded/ + tracing/   # ① 母版真源：唯一真源，跨版本演进
├── daily/                           # ② 每日基础用例：精选子集（ID 清单）
├── versions/<版本>/                 # ③ 版本测试设计：按版本冻结快照
└── issues/<编号>-<slug>/            # ④ 问题回归用例：按 issue 归档
```

- **daily** 只存「ID 清单 + 门禁分级」，不复制真源；每日多 agent 按此执行。
- **versions** 是版本冻结切片（测试设计文档 + CSV 快照），用于版本对比/审计。
- **issues** 是缺陷级增补（复现 + 断言契约 + 修复结论），P0 同步进 daily 盯防。

## 编号规则

- 用例 ID 格式：`D<维度>-<序号>`（设计级），`EXP-<矩阵>-<序号>`（展开级）
- 维度：D1 安装 / D2 认证 / D3 功能 / D4 安全 / D5 客户端 / D6 性能 / D7 兼容 / D8 质量 / D9 协议 / D10 评测
- 优先级：P0 必测（安全/中断级）/ P1 应测 / P2 可测；**禁止剪枝集**（D4 全量、D1-1/3/5、D9 全量、D10 核心评测集）任何裁剪不得触碰

## 用例演进三铁律（§5.2）

1. **ID 一经分配永不复用**——趋势追踪与历史结果引用的基础
2. **废弃用 OBSOLETE 标记**（保留历史结果），不物理删除
3. **修改 = 新 ID + 关联旧 ID**（注明 supersedes），保证跨版本结果可对比

## 状态追踪

执行时复制到 `results/ITER-NNN-<YYYYMMDDHHmmss>/` 或执行追踪母版（Excel/腾讯文档）。设计级和展开级均分离 `设计状态` 与 `执行状态`：设计字段完整不等于执行通过；未执行统一为 `NOT_RUN`，历史 `UNASSESSED` 仅保留为历史状态。执行状态可为 PASS / FAIL / BLOCKED / SPEC-MISMATCH / NOT_RUN；BLOCKED 不计入通过率分母（§5.1 度量口径）。
