# 用例体系说明

本目录存放 huaweicloud-devkit 测试用例**母版**（跨版本演进，非执行结果）。

## 文件

| 路径 | 内容 |
|---|---|
| `design/用例矩阵-设计级.csv` | 设计级用例 153 条（D1–D10，12 列完整字段） |
| `design/gen_matrix.py` | 矩阵生成脚本（修改后重跑保证可复现） |
| `expanded/用例矩阵-展开级.csv` | 展开级用例 107 条（D5 客户端矩阵 70 / D3-C4 服务矩阵 22 / D10 评测集 15） |

## 编号规则

- 用例 ID 格式：`D<维度>-<序号>`（设计级），`EXP-<矩阵>-<序号>`（展开级）
- 维度：D1 安装 / D2 认证 / D3 功能 / D4 安全 / D5 客户端 / D6 性能 / D7 兼容 / D8 质量 / D9 协议 / D10 评测
- 优先级：P0 必测（安全/中断级）/ P1 应测 / P2 可测；**禁止剪枝集**（D4 全量、D1-1/3/5、D9 全量、D10 核心评测集）任何裁剪不得触碰

## 用例演进三铁律（§5.2）

1. **ID 一经分配永不复用**——趋势追踪与历史结果引用的基础
2. **废弃用 OBSOLETE 标记**（保留历史结果），不物理删除
3. **修改 = 新 ID + 关联旧 ID**（注明 supersedes），保证跨版本结果可对比

## 状态追踪

执行时复制到 `results/ITER-NNN/` 或执行追踪母版（Excel/腾讯文档），状态列：未执行 / 通过 / 失败 / 阻塞(BLOCKED) / 跳过。BLOCKED 不计入通过率分母（§5.1 度量口径）。
