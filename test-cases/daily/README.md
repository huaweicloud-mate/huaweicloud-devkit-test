# daily 每日基础用例集

本目录是**每日执行的标准输入**——从母版真源 `design/` + `expanded/` 派生的「精选子集」，多 agent 每日按此执行，不跑全量 179+137。

## 文件

| 路径 | 内容 | 列 |
|---|---|---|
| `用例矩阵-设计级.csv` | 每日基础设计级用例（当前 77 条） | 母版完整 27 列（纯设计，同列名/列序） |
| `用例矩阵-展开级.csv` | 每日基础展开级用例（当前 49 条） | 母版完整 24 列（纯设计，同列名/列序） |

> **列与母版完全一致**：daily 是「母版精选子集」，直接复用母版完整列结构（设计级 27 列 / 展开级 24 列，纯设计定义、无执行态），只筛行、不裁剪列，母版演进时自动跟随。
> 执行状态与结果只回填 `results/<客户端>/<日期>-<IP>/<OS>/`，不落在 daily 用例里（`init_day.py` 复制时追加回填列）。

## 精选规则

| 层 | 规则 | 当前数量 |
|---|---|---|
| 设计级 | 禁止剪枝(D4 全量 + D1-1/3/5 + D9 全量 + D10-1~4) + P0 全量 + P1 冒烟(含 D3-C4/D1-58) − DAILY_EXCLUDE | 77 |
| 展开级 | 源用例 ∈ 设计级精选集（保留全部多终端展开行） | 49 |

- **禁止剪枝集**：README §5.2 钦定，任何裁剪不得触碰。
- **DAILY_EXCLUDE（2026-09-15 起）**：仅「真·外部依赖」移出每日——真云创建-销毁（D3-C4→连带 EXP-C4 22 服务，高危计费待三档拆分）、LLM 行为评测 harness（D10-1 工具描述可选 / D10-2 skill 激活率 / D10-5 多轮完成率）。其余已撤回：D6-1/3/4（压测探针本地可跑）、D9-6（有历史结论）、D2-1（三端落位拆源码级）、D4-13/D4-14（只读子账号 + CTS 已就绪）。D10-3 路由与 D10-4 P0 安全保留。
- 生成脚本：`test-cases/gen_daily.py`（规则改后重跑）。

## 每日执行口径

1. `scripts/init_day.py` **已改为复制本目录精选**（设计级 77 + 展开级 49，不再是母版全量 179），本目录是每日执行的**唯一用例来源**；`build_summary.py`/`gen_summary.py` 汇总也读本目录精选。
2. **P0/禁止剪枝项 FAIL 即阻断**，不得虚报 PASS（`scripts/verify_no_fake_pass.py` 把关）。
3. 执行结果回填 `results/<客户端>/<日期>-<IP>/<OS>/`，与母版追踪表对齐。
