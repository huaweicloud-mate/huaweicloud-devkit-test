# daily 每日基础用例集

本目录是**每日执行的标准输入**——从母版真源 `design/` + `expanded/` 派生的「精选子集」，多 agent 每日按此执行，不跑全量 163+137。

## 文件

| 路径 | 内容 | 列 |
|---|---|---|
| `用例矩阵-设计级.csv` | 每日基础设计级用例（当前 81 条） | 母版前 12 个设计字段列（`ID…展开规则`） |
| `用例矩阵-展开级.csv` | 每日基础展开级用例（当前 71 条） | 母版前 7 个用例内容列（`ID…预期结果`） |

> **列保持母版设计字段、不带执行状态/结果**：两份 CSV 只保留「用例定义」，去掉了母版里的
> `用例当前状态/设计状态/执行状态/requiredEvidence/blockedReason/owner/依赖/evidencePath`、
> `terminal/agent/OS` 环境元数据、`status/observedAt` 等**执行关联列**。
> 执行状态与结果只回填 `results/<客户端>/<日期>-<IP>/<OS>/`，不落在 daily 用例里。

## 精选规则

| 层 | 规则 | 当前数量 |
|---|---|---|
| 设计级 | 禁止剪枝(D4 全量 + D1-1/3/5 + D9 全量 + D10-1~4) + P0 全量 + P1 冒烟(含 D3-C4/D1-58) | 81 |
| 展开级 | 源用例 ∈ 设计级精选集（保留全部多终端展开行） | 71 |

- **禁止剪枝集**：README §5.2 钦定，任何裁剪不得触碰。
- 生成脚本：`test-cases/gen_daily.py`（规则改后重跑）。

## 每日执行口径

1. 执行入口仍是 `AGENTS.md` + `scripts/init_day.py`；本目录作为「当天跑哪些」的**用例来源**。
2. **P0/禁止剪枝项 FAIL 即阻断**，不得虚报 PASS（`scripts/verify_no_fake_pass.py` 把关）。
3. 执行结果回填 `results/<客户端>/<日期>-<IP>/<OS>/`，与母版追踪表对齐。
