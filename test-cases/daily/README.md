# daily 每日基础用例集

本目录是**每日执行的标准输入**——从母版真源 `design/` 派生的「精选子集」，多 agent 每日按此清单执行，不跑全量 163+137。

## 与母版的关系

- **真源**：`test-cases/design/用例矩阵-设计级.csv`（唯一，跨版本演进）
- **本清单**：`基础用例清单.csv` 只存 **ID 引用 + 门禁分级**，不复制真源内容，避免三处漂移
- 生成脚本：`test-cases/gen_daily.py`（规则改了跑它重生成）

## 每日执行口径

1. 执行入口仍是 `AGENTS.md` + `scripts/init_day.py`；本清单作为「当天跑哪些」的**选择依据**，init_day 按清单过滤生成执行包（或全量复制后按门禁排序 P0→P1→P2）。
2. **门禁顺序**：禁止剪枝 = P0 必跑 > P1 冒烟（禁止剪枝内的 P0 安全项最优先）。
3. **P0/禁止剪枝项 FAIL 即阻断**，不得虚报 PASS（`scripts/verify_no_fake_pass.py` 把关）。
4. 执行结果仍回填 `results/<客户端>/<日期>-<IP>/<OS>/`，与母版追踪表对齐。

## 清单列

`ID, 维度, 标题, 优先级, 门禁, 当前执行状态`（当前执行状态从母版同步，仅供排期参考）
