## 五、口径与边界（勿越界）

1. 三指标**只用于同一 SUT 内「基线版 ↔ 新版」相对对照**，不作绝对判定（换客户端/模型即失效）。
2. `fails`/`clarifications` 是**特征词近似计数**（`eval/harness/ux-metrics.mjs` 的模式表），受答复措辞影响；
   `tokens`/`steps` 是硬计数（网关 usage / MCP 调用次数）。
3. 本轮的诚实边界：**两个版本都是「体验缺口尚未修复」的当前发布状态**，因此本表是**基线对照**，
   用途是①验证无退化、②为修复后复跑提供对照物 —— **不能**据此说「新版体验更好/更差」。
4. 判定线（三项不劣化 + 至少一项改善）在 `Δ=±1` 量级下过于严格/敏感：建议把**采样数 ≥3 取中位**
   固化进口径（本轮已做），并考虑对 `steps` 引入「±1 视为持平」的噪声带（**需另行评审，本轮不改口径**）。
