## 一、学习内容（AI 测试前沿知识）

### 1. 语义断言（Semantic Assertion）
- AI/Agent 输出非确定性，无法精确断言同提示词的逐字输出
- 改为断言**行为语义**：输出是否含关键信息、凭证是否脱敏、工具/服务调用序列是否合理
- 典型形态：`断言输出包含"ECS"` 而非 `断言输出 == "List: ECS, ..."`；`断言输出不含 AK/SK 明文`

### 2. 录制回放（Record & Playback）
- 录制真实 Agent 会话为 JSON Lines（用户提示词 + 工具调用序列 + 入参出参）
- 回放时 Mock MCP 入口，比较实际输出与录制基线的**动作序列语义等价性**
- 价值：AI Agent 回归测试的核心手段，让"非确定性系统"具备可回归性

### 3. 差异分类策略（Diff Classification）
- 测试失败不直接报 FAIL，先分类，决定处理方式：

| 差异类型 | 处理 |
|---|---|
| 调用顺序变化但语义等价 | ✅ PASS（记录模式更新）|
| 参数变化但结果等价 | ✅ PASS（更新基线）|
| 缺少必要调用 | ❌ FAIL |
| 调用了禁止工具 / 输出含敏感信息 | ❌ FAIL（安全违规）|
| 语义不符（用户意图未满足） | ❌ FAIL |

### 4. AI Test Manager 三层生成模型
- **Layer 1 策略**：Manager 输出影响域 + 风险定级 + 测试范围（粗粒度）
- **Layer 2 使命**：调度器输出每个 Worker 的任务描述（scope + constraints + criteria，中粒度）
- **Layer 3 用例**：Worker 自主展开具体步骤（正常/边界/异常，细粒度）
- 核心取舍：Manager 不生成完整用例 → 不被细节淹没；Worker 有领域上下文 → 用例更精准；天然可并发展开

### 5. 语义质量分析器
- 安全检查：输出含 AK/SK/token → 自动 FAIL；调用未授权工具 → 自动 FAIL
- 差异决策：`SEMANTIC_EQUIVALENT` / `MINOR_FORMAT_CHANGE` / `SECURITY_REGRESSION` / `INTENT_NOT_MET`
- fail-closed 原则：输入非法 → deny，禁止 fail-open

### 6. 安全测试专项
- 凭证脱敏矩阵：所有输出路径（对象/数组/字符串/日志）不得含 raw 凭证
- 写操作拦截矩阵：每个写语义工具必须走审批门；只读操作放行
- 对抗性：shell 包裹穿透（`sh -c "hcloud ..."`）、命令拼接、大小写混淆
