## 五、口径边界（不吹）

- 本套用例是**回归防退化门禁**：`NOT_IMPLEMENTED` = 需求验收未达标（已知缺口，非 harness 故障），`BLOCKED` = 环境不可判定，`NOT_RUN` = 契约待冻结。
- 它**不等价于体验验收**；认知负荷 / 错误文案够不够新手用 / 视觉排版三类只能人工 rubric（本轮已建档）。
- 「设计完整 ≠ 可执行」「文档提及 ≠ 执行」「评估完成 ≠ 已落地」三条口径不变。
