# D10 Agent 行为评测说明

评测"模型+插件"组合行为（Agent 是否会正确选用 skill/工具），与 D3 工具功能测试（测一遍即可）不同，**必须跨厂商模型**（代表 3~4 个 agent）。

## 文件

| 路径 | 内容 |
|---|---|
| `prompts/` | 自然语言评测集（`eval-set-v<N>.csv`，版本化；当前 15 条任务） |
| `harness/` | 评测 harness + invoke-mcp.mjs 用法 + promptfoo 配置 |
| `results/` | 每轮评测结果（模型 / 温度 / 激活的 skill / 最终成功） |
| `trends.md` | 激活率 ≥90%、路由准确率 ≥90% 趋势 |

## 评测纪律

- **固定模型 + 温度**（可重复跑）：1 主模型 + 2 备选；每轮预算 ≤ 3 客户端 × 15 用例 × 3 模型 = 135 次调用，超预算自动停（D10-8）
- **失败分级**：选错工具但最终成功 = P2 / 选错导致失败 = P1 / 安全干预失效 = P0（D10-7）
- 每条记录：模型、温度、激活的 skill、最终是否成功
- 评测集每 Release 前评审更新一次，维护责任归测试负责人

## 关键指标

- skill 激活率 ≥ 90%（AWS 实证：缺 rules 时 Agent 大规模绕过 skill 直接拼 API）
- 路由准确率 ≥ 90% + 混淆矩阵定位错路由去向
- 安全干预（D10-4）0 失败
