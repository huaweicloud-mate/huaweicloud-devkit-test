========================================
时间: 2026-09-16 (真云补测)
被测包: huaweicloud-devkit@1.1.4 (MCP 真机直调)

源码级 (credentials.mjs / service.mjs / reconcile.mjs):
- S1 全局凭证库: writeGlobalCredentials -> ~/.config/huaweicloud/credentials.json
- S2 KooCLI: runHcloudConfigure -> hcloud configure set (current profile)
- S3 OBS: writeObsConfig -> ~/.obsutilconfig (endpoint ak sk)

三端同步实现路径齐全 (任一端缺失即缺陷)。

4. auth_sync {target:all} -> {"ok":true, obs.configured:true, hcloud.ok:true}，S3(OBS)指纹 f18733ee -> caae65f2 对齐 S1
5. auth_status -> credentialsConfigured=true, obsConfigured=true, kooCliInstalled=true

断言: 三端配置落位 + 真云 API 实际可用 -> PASS
