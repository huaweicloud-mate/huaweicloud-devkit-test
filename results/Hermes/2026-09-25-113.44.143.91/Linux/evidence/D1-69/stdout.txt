--- huaweicloud-devkit help ---

╔══════════════════════════════════════════════╗
║     HuaweiCloud DevKit v1.1.7                 ║
║     https://github.com/huaweicloud   ║
╚══════════════════════════════════════════════╝

Usage: npx huaweicloud-devkit <command> [--target <opencode|codex|codearts|codearts-work|workbuddy|dsh|officeace|hermes|openclaw|atomcode|all>]

Commands:
  install      Install skills, MCP server, safety policy
  uninstall    Remove installed files
  update       Update to latest version
  reinstall    Full clean reinstall
  status       Show installation status
  doctor       Self-check: hcloud, MCP, skills, auth
  install-hcloud  Show KooCLI install commands for your OS
  auth         Manage unified auth: init | sync | status | reconcile
  proxy        Manage proxy config: init | show | clear
  version      Print CLI version and installed plugin version per agent
  help         Show this help

Options:
  --target     Target agent: opencode (default), codex, codearts, codearts-work, workbuddy, dsh, officeace, hermes, openclaw, atomcode, all
  --version    Print CLI version and installed plugin version per agent
  --clean-kocli   (with: uninstall --target all) also remove KooCLI
  --clean-obs     (with: uninstall --target all) also remove OBS config
  --clean-global  (with: uninstall --target all) also remove KooCLI + OBS config

Examples:
  npx huaweicloud-devkit install
  npx huaweicloud-devkit install --target codex
  npx huaweicloud-devkit install --target codearts
  npx huaweicloud-devkit install --target codearts-work
  npx huaweicloud-devkit install --target workbuddy
  npx huaweicloud-devkit install --target dsh
  npx huaweicloud-devkit install --target officeace
  npx huaweicloud-devkit install --target hermes
  npx huaweicloud-devkit install --target atomcode
  npx huaweicloud-devkit install --target all
  npx huaweicloud-devkit auth init
help exit=0
