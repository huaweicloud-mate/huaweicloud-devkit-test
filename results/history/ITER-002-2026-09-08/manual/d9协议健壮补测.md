## OBS-15（候选）：MCP stdio server 对畸形帧无容错，崩溃退出

- **现象**：stdin 收到非法 JSON 行 → `handleMessage(JSON.parse(line))` 抛 SyntaxError 未捕获 → 进程退出（exit 1）
- **影响**：① 兼容性差：任何半开/截断/双写帧即可 kill server（客户端长时间连接下偶发坏帧概率不低）；② 无恢复路径（进程死亡，宿主需重连）；③ 与 D9-5 期望的"坏帧忽略/报错继续服务"不符
- **修复建议**：`parseMessage` 加 try/catch；坏帧写 stderr 告警 + 继续服务（或返回 JSON-RPC error -32700 Parse error）；补单测畸形帧用例
- 同族：#560（OfficeAce CLOSE_TIMEOUT 为宿主侧清理判定）——本报告是**插件自身 stdio 解析健壮性**
