# 度量与趋势说明

跨迭代质量度量（§5.1），每迭代末更新。

## 文件

| 文件 | 内容 |
|---|---|
| `execution.csv` | 每轮：时间戳 / 迭代 / 计划用例 / 已执行 / 通过 / 阻塞 / 执行率 / 通过率 / 自动化覆盖率 |
| `defects.csv` | 缺陷：ID / 级别(P0/P1/P2) / 新增迭代 / 状态(开/修/关/backlog) / 关联用例 |
| `dashboard.md` | 质量仪表盘（每迭代末更新一页，随 T6 报告呈报） |

## 指标口径

| 度量项 | 口径 |
|---|---|
| 用例执行率 | 已执行 / 计划执行（BLOCKED 不计入分母） |
| 用例通过率 | 通过 / 已执行（含 PARTIAL 折算） |
| 缺陷密度 | (P0+P1) / 已执行用例 ×100 |
| D10 激活率 / 路由准确率 | 评测集跑分（固定模型+温度，见 ../eval/） |

## 趋势可对比前提

用例 ID 永不复用 + 废弃标 OBSOLETE（见 ../test-cases/README.md）——度量数据跨版本可比。
