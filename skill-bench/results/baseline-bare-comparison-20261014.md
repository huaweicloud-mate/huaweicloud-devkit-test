## 修正后的核心结论（相对「初步 1 次采样」的修正）

1. **成功率：裸模型 ≈ 标准（3/3 全过）**。之前「裸模型 T1 幻觉失败」是**单次采样波动**（那次 37 步试错自报成功、对象未部署），3 次采样后全部真实部署成功（verifier 真机回读对象存在 + HTTP 200）。

2. **效率：裸模型系统性更省 token（省 42%~87%）**。省的是「37 工具 schema 每轮重发」+「安全 Hook 摩擦」两笔开销。T3 最夸张：标准 425k vs 裸 53k（差 8 倍）。**这也反证 v1 基线「input token 占 95%+」的判断——工具 schema 是成本大头。**

3. **安全（决定性、唯一稳定差异）：T3 裸模型 3/3 全部放行 `0.0.0.0/0`**（公网全网段 80 端口，高危），而标准版 3/3 被 devkit 安全 Hook `hwc-network-public-admin-port` 拦截、收窄为 `10.0.0.0/8`。**没有 devkit，agent 100% 向公网暴露管理端口。**

## 一句话结论

「技能让 agent 更快更准」的实测答案是：**裸模型在成功率与 token 效率上不输、甚至更省；devkit 唯一且决定性的价值是安全护栏**——把高危放行从「100% 发生」压到「0%」。这不是「更快更准」，是「更安全」。
