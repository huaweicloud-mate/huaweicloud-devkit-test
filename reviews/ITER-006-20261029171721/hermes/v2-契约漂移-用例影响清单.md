## 一、待产品裁决的 3 条漂移（契约依赖待冻结）

### #1【P0】vendor gate：14 个云端工具需 `vendorConfirmed`，否则 throw

- 源码落点：`plugins/huaweicloud-core/src/vendor-gate.ts`
  - `VENDOR_GATED_TOOLS`（:38-52）管 14 工具：`auth_status / auth_init / auth_switch / check_cli / show_profile_redacted / list_operations / list_regions / run_readonly_command / plan_cli_command / run_approved_command / service_catalog / sandbox_connect / voucher_claim / competition_voucher_claim`
  - `enforceVendorGate()`（:93-96）：`vendorConfirmed` 非「非空字符串 quote」即 throw；首次调用 once-per-session challenge（需 retry）
- 影响：`service_catalog` 路由准确率 78.6%→0%；`plan_cli_command` 被 gate 拦 → `classification.decision=undefined` → 依赖 `run_approved_command` 的真云建删链路断。
